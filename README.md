# Durand Tech Systen — Website

Site institucional responsivo desenvolvido com HTML5, CSS3 e JavaScript puro.

## Estrutura
- `index.html` — conteúdo e estrutura semântica
- `css/styles.css` — identidade visual, componentes e responsividade
- `js/main.js` — menu mobile, animações, ano e links de contato

## Como executar
Abra `index.html` diretamente no navegador. Não exige instalação, framework ou build.

## Personalização rápida
- Cores principais: variáveis CSS no início de `css/styles.css` (`--neon`, `--bg`, etc.).
- Textos e seções: edite `index.html`.
- WhatsApp: procure por `53997073648` em `index.html` e `js/main.js` e substitua pelo número desejado, no formato internacional sem `+` ou espaços.
- Fontes: o projeto usa Google Fonts (DM Sans e Space Grotesk); com internet, elas são carregadas externamente.

## Observação
O site foi preparado como uma base editável. Antes de publicar, revise textos, links e informações comerciais.
